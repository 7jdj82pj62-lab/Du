Installer en PWA sur iOS (iPhone / iPad)

  1. Héebergez ce fichier HTML sur GitHub Pages (voir les étapes ci-dessous).
  2. Ouvrez le lien de votre site dans le navigateur Safari sur votre iPhone.
  3. Appuyez sur le bouton Partager dans la barre d'outils en bas de Safari.
  4. Faites défiler le menu et sélectionnez « Sur l'écran d'accueil ».
  5. Confirmez en appuyant sur Ajouter. L'application s'installera comme une application native plein écran !

Hébergement Gratuit sur GitHub Pages

  • Créez un nouveau dépôt (repository) public sur GitHub (ex: patrimoine-tracker).
  • Renommez ce fichier HTML en index.html et uploadez-le à la racine du dépôt.
  • Dans votre dépôt GitHub, allez dans l'onglet Settings > Pages.
  • Sous Build and deployment, sélectionnez la branche main (ou master) et le dossier / (root), puis cliquez sur Save.
  • Votre application sera accessible en ligne gratuitement sous quelques minutes !

Sauvegarde & Données

Toutes vos données financières sont stockées localement dans votre navigateur (localStorage). Rien n'est envoyé sur un serveur externe, garantissant une confidentialité totale.
